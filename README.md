# Veille ParkStay – Cape Le Grand

Vérifie toutes les heures, de 7 h à 22 h (heure française), s'il y a une place libre
à **Lucky Bay** ou **Le Grand Beach** pour les nuits du 30/12/2026 au 2/01/2027.

S'il y en a une, une *issue* « Place libre à Cape Le Grand ! » est créée : GitHub t'envoie un e-mail.
Ferme l'issue une fois réservé : tant qu'elle est ouverte, tu ne reçois pas de nouvel e-mail.

- Lancer une vérification tout de suite : onglet **Actions** → *Veille Lucky Bay* → **Run workflow**.
- Arrêter la veille : onglet **Actions** → *Veille Lucky Bay* → **⋯** → **Disable workflow**.
